# Contributing To CASEBOOK

Read `AGENTS.md`, then use `docs/README.md` to locate the affected authority.
Link a stable work item, use a short-lived branch, keep the change cohesive,
and run the risk-proportionate `./dev` checks before opening a pull request.

New tools and better methods are welcome when they solve a demonstrated
problem and include cost, risk, compatibility, success, and removal evidence.
