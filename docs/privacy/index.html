Privacy

CASEBOOK has no account system or analytics. Your saved cases stay in your browser.

Saved cases and shared links

The shortlist uses browser-local storage. Remove saved cases in the catalogue, or clear this site’s data in your browser to erase it. Storage belongs to this browser and is not an account or a synchronised backup.

Shared URLs can contain selected filters, a case ID or comparison IDs. Anyone receiving the link can read those selections. Avoid adding private information to shared URLs.

Hosting and source images

GitHub Pages hosts this site. Visiting it makes normal web requests to GitHub’s hosting infrastructure. Optimised catalogue images are served by this site. Full-size gallery images may be fetched from their recorded external hosts, which receive image requests and network information such as your IP address. Following a seller link opens that seller’s service under its own policies.

GitHub privacy statement

Advertising is currently off

Optional Google AdSense is not active. It may be activated only after real publisher and ad-unit setup, site approval and certified consent-management configuration are verified. Required consent must be established before ad requests. Browsing the catalogue does not give consent to advertising.
